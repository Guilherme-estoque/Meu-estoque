Configurações

Instalar no Android

Depois de hospedar esta pasta em um endereço HTTPS, abra o endereço no Chrome, toque no menu ⋮ e escolha Instalar app ou Adicionar à tela inicial. Para instalar como PWA e usar offline, o site precisa ser servido por HTTPS.

Atenção: os dados não são enviados para nuvem. Se os dados do site forem apagados pelo navegador, só será possível recuperá-los com um backup.

Apagar dados

Remove todos os cadastros e movimentações deste aparelho. Exporte um backup antes.
